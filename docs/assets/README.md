# Repository visuals

These images explain Haldir; they are not financial evidence.

- **haldir-cover.jpg:** composed from Haldir's existing landing artwork (`sky-background.webp`, `foliage-distant.webp`, `foliage-near.webp`) and original `haldir-negative.svg` mark, served under `https://haldir.ldt.sh/assets/`. Uses the existing Manrope typography. No replacement logo was generated.
- **scripted-demo.png:** unretouched browser capture of `https://haldir.ldt.sh/demo` on 14 November 2026, at 1440 × 1050. The capture follows an explicitly fictional job through presenter-confirmed funding, S03 and S04. No wallet, real funds, model invocation or public-chain operation was used. The simulation disclosure is retained in the image.
- **spending-boundary.png:** an explanatory illustration of the native payment boundary. It omits lower-level caller, operation-identity, in-flight and callback checks for readability; see [Architecture](../ARCHITECTURE.md) for the full description. Payment does not itself guarantee delivery.

The original brand artwork and screenshot disclosures are preserved. These assets do not change the project's unresolved license status or grant additional rights to third-party material.
